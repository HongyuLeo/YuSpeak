# YuSpeak v0.1.0 — Development Preview
Local Windows bilingual subtitle application with WASAPI capture, modular offline
inference adapters, Qt overlay, tray/hotkeys, model downloads and history exports.
17 module tests and native system capture/UI smoke checks passed. Full bilingual
inference, GPU, microphone, offline and soak acceptance remain incomplete.
Models and NVIDIA runtimes are not bundled. No installer. Do not publish as a
stable release before reviewing CHATGPT_HANDOFF.md and third-party licenses.

Core ASR, CUDA inference and the real bilingual caption chain have not been
fully accepted. Binary Pre-release publication is deferred because runtime
redistribution compliance review remains incomplete. Source and documentation
handoff uses https://github.com/HongyuLeo/YuSpeak; see PUBLICATION_STATUS.md.
